TaqVox Sidi Aïch Voice V6

Correction voix:
- gh est forcé en غ, pas en ع.
- 3 est forcé en ع.
- 7 est forcé en ح.
- 9 est forcé en ق.
- v est forcé en ڤ.

La version V6 utilise un dictionnaire mot par mot avant les règles générales.
Exemples:
Vghigh => ڤْغِيغْ
I9ar7iyi => إيقارْحِيّي
A3bod => اعْبودْ
I7ma => يحْما
Dewriyi => دَوْرِيّي
9a3diyi => قاعْدِيّي

Important: la voix iPhone/Chrome reste provisoire. Le vrai résultat naturel viendra avec le serveur IA/Tobii.
