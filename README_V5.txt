TaqVox Sidi Aïch Voice V5

Cette version applique une conversion avant la voix :
- gh -> غ
- 3 -> ع
- 7 -> ح
- 9 -> ق
- v -> ڤ

Exemple : Vghigh aman devient approximativement ڤغيغ امان pour la voix iPhone arabe.

Important : ce n’est pas encore une vraie voix IA kabyle parfaite. C’est une amélioration provisoire pour que l’iPhone prononce mieux.
La vraie voix IA kabyle cloud sera branchée plus tard via CLOUD_TTS_URL dans app.js.
