TaqVox Sidi Aïch IA V4

Cette version utilise l’écriture familiale/WhatsApp :
- gh = غ
- 3 = ع
- 7 = ح
- 9 = ق

Exemples :
- Vghigh aman -> vɣiɣ aman
- I9ar7iyi -> iqarḥ-iyi
- A3bod -> aɛbod
- I7ma -> iḥma
- 9a3diyi -> qaɛd-iyi

L’application affiche les mots comme vous les écrivez, mais elle prépare une version interne pour la voix IA.
Pour l’instant sur iPhone, la voix est provisoire. Quand le serveur cloud sera prêt, il utilisera directement cette conversion.
