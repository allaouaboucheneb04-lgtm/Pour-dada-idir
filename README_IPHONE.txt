TaqVox iPhone Auto V3

Cette version est faite pour iPhone sans PC.
Il n'y a plus de champ à remplir.

Important :
- Tant que le serveur cloud IA n'est pas en ligne, l'application utilise la voix iPhone provisoire.
- Pour activer la vraie voix IA kabyle, il faut héberger le serveur /tts puis mettre son URL dans app.js : CLOUD_TTS_URL.

Fichiers :
- index.html : application
- app.js : logique + adresse cloud TTS
- style.css : design
- server/ : serveur IA à héberger plus tard
